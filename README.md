# Personal Portfolio

A modern portfolio built with React, Tailwind CSS, and Framer Motion.

## Setup

1. Open the `portfolio` folder in your terminal.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```

## Personalization

- Update project links in `src/data/projects.ts`.
- Customize skills in `src/data/skills.ts`.
- Replace the sample contact and personal details if needed in `src/components/Hero.tsx`, `src/components/Contact.tsx`, and `index.html`.
- Add your resume PDF as `public/resume.pdf` so the Resume button opens your live resume.

## Features

- React
- Tailwind CSS styling
- Framer Motion animations
- Responsive layout for desktop and mobile
- Accessible navigation and contact form
